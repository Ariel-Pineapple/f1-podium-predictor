# 1. Objetivo del Sistema

El sistema tiene como objetivo predecir la probabilidad de que un piloto de Fórmula 1 finalice una carrera dentro de las tres primeras posiciones (podio), utilizando un modelo de Machine Learning entrenado con información histórica de competencias.

El sistema fue desarrollado con fines académicos para demostrar el ciclo de vida completo de un proyecto de Inteligencia Artificial, desde la preparación de los datos hasta el despliegue del modelo como servicio web.

---

# 2. Caso de uso

El sistema permite que un usuario ingrese información básica de una carrera:

- Piloto
- Escudería
- Circuito
- Año
- Posición de salida

A partir de estos datos el sistema devuelve:

- Predicción (Podio / No Podio)
- Probabilidad estimada

# 12. Riesgos

| Riesgo | Mitigación |
|---------|------------|
| Datos históricos incompletos | Validación previa del dataset |
| Sobreajuste | Train/Test Split |
| Nuevos pilotos o escuderías | OneHotEncoder(handle_unknown="ignore") |
| Degradación del modelo | Reentrenamiento periódico |

---

# 13. Limitaciones

El modelo no considera:

- Clima
- Fallas mecánicas
- Safety Cars
- Penalizaciones
- Estado físico del piloto
- Estrategias de pits

Por lo tanto, la predicción representa únicamente una estimación basada en información histórica.
